# 个人公积金、各类国家补贴指引和自查 Agent

上海租房场景的手机端信息提示。同一段租约会分开判断两件事：

- **住房租金专项附加扣除**：减少的是应纳税所得额，不是退回的现金。
- **市场租赁住房公积金提取**：动用的是本人账户里已归属个人的资金，不是补贴。

两笔金额始终分开展示，不会加总成「能领回」。本应用不登录税务机关或公积金中心，也不代办申请。

政策口径复核日期：**2026-09-27**。结果只是信息提示，不是官方资格认定。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端里的本地地址，建议用手机宽度查看。首页展开「演示样本」可以直接看完整结果和几条反例。

```bash
npm run build    # 类型检查并产出 dist/
npm run preview  # 预览构建结果
npm run lint
```
